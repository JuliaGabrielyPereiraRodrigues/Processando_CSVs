# Processamento e Análise de Dados CSV

Projeto acadêmico individual desenvolvido em Python para processamento, consolidação e análise de arquivos CSV contendo dados relacionados aos tribunais e às Metas do Poder Judiciário.

## Tecnologias utilizadas
- Python
- Pandas
- Multiprocessing

## Funcionalidades
- Leitura e processamento de múltiplos arquivos CSV.
- Consolidação de dados em um único arquivo.
- Normalização e classificação dos ramos da Justiça.
- Cálculo de indicadores relacionados às Metas do Judiciário.
- Processamento paralelo utilizando múltiplos núcleos do processador.
- Geração de arquivos CSV com os resultados consolidados e os indicadores calculados.
- Tratamento de exceções durante o processamento.

## Arquivos gerados
- `Consolidado.csv`: reúne os dados dos arquivos de entrada.
- `ResumoMetas.csv`: apresenta os resultados dos cálculos das metas por tribunal.

## Objetivo
Aplicar conceitos de programação em Python, manipulação de dados, automação e processamento paralelo para otimizar a análise de grandes conjuntos de informações.
